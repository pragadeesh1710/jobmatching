About the Role Matching System

In standard campus placements and technical interviews, students often wonder which engineering career path best matches their coursework and programming competencies. RoleMatch solves this by algorithmically comparing student skill profiles with predefined industry role requirements.

1. Profile & Skill Database

Students register their profile and choose from 20+ standardized skills (Java, Python, HTML/CSS, React, MySQL, Docker, etc.). All user details and relational skill mappings are permanently stored in MySQL tables via JDBC.

2. Real-time AJAX Matching Algorithm

Whenever students add or remove skills, an asynchronous AJAX request is dispatched to MatchServlet. The server computes match percentage (matched / total * 100) and dynamically ranks all roles with instant visual progress bars.

3. XML & XPath Query Engine

In addition to relational tables, the system maintains a structured roles.xml repository. XPathServlet demonstrates standard W3C XPath parsing to filter roles by category, required skills, and salary bands.
